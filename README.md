# もし株（if-kabu）株トレード練習

実際の日本株の日足データを使って、仮想の資金で売買を練習する Web アプリです。実際の注文は一切出ません。

## 使い方

- **リアル**：「次の始値で（予約）」を選ぶと、次の取引日の朝の始値で約定します。「すぐ約定」なら最新の株価（取引中は約20分遅れの現在値、引け後は終値）で約定します。
- **リプレイ**：過去5年のどこかの日から始めて、1日ずつ進めながら売買します。終了すると期間と結果がわかります。

売買・保有・履歴はこの端末のブラウザに保存されます。

## データの更新

`.github/workflows/update-data.yml` が平日の 9:23〜14:23 と 16:23〜翌0:23（日本時間）に1時間おきで `scripts/fetch.py` を実行し、Yahoo!ファイナンスの日足を `data/` に保存します。Actions タブの「株価データ更新」から手動でも実行できます。

## 銘柄を増やす

`tickers.json` に `{"code": "証券コード", "name": "銘柄名"}` を追加して push すると、自動でデータ取得が走ります。
