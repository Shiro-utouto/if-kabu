# もし株（if-kabu）株トレード練習

実際の日本株の日足データを使って、仮想の資金で売買を練習する Web アプリです。実際の注文は一切出ません。

## 使い方

- **リアル**：最新の終値で売買します。データは平日の夕方に自動で更新されるので、翌日以降に損益が動きます。
- **リプレイ**：過去5年のどこかの日から始めて、1日ずつ進めながら売買します。終了すると期間と結果がわかります。

売買・保有・履歴はこの端末のブラウザに保存されます。

## データの更新

`.github/workflows/update-data.yml` が平日 16:40 と 20:10（日本時間）に `scripts/fetch.py` を実行し、Yahoo!ファイナンスの日足を `data/` に保存します。Actions タブの「株価データ更新」から手動でも実行できます。

## 銘柄を増やす

`tickers.json` に `{"code": "証券コード", "name": "銘柄名"}` を追加して push すると、自動でデータ取得が走ります。
